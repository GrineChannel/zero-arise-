# NPC intelligence evolution — approved

NPCs learn by practice, remember outcomes, exchange knowledge and experiment with predefined technology/magic components. Institutions aggregate research in remote regions.

## Modules
- skills: experience-based progression
- experience: bounded outcome ledger
- knowledge: bounded known discoveries
- research_catalog: initial technology and magic prerequisite graph
- research: incremental project progress
- teaching: knowledge transfer
- discovery: bounded probabilistic experiments
- collective_research: organization-level research state

## Constraints
No arbitrary code generation, no separate language model per NPC. Discovery is bounded by authored game effects. Remote simulation must use scheduled aggregate updates.

## Integration remaining
Persist per-NPC and institution data; connect to NPC decision-making, factions, Bedrock entities, world clock and save system. Balance probabilities and validate on Android.
